# Full-Stack Restaurant Management System (CMS) - Showcase

*Note: This repository serves as a technical showcase. Because this system is currently live in production and actively used by a commercial client (Göreme Women's Cooperative), the source code is kept **PRIVATE** for security and confidentiality reasons.*

## 📌 Project Overview
This project is an end-to-end restaurant web application featuring a custom Content Management System (CMS). It was designed to enhance the digital presence of the cooperative and streamline their daily operations through a secure admin panel.

## ⚙️ Backend & Architecture (Node.js & MySQL)
The backend was built to handle complex relational data, media uploads, and strict authorization workflows.
*   **RESTful API:** Developed using **Node.js and Express.js** to serve both the client-facing website and the internal admin panel.
*   **Database Schema:** Relational data modeling using **MySQL** to handle dynamic menu items, categories, and specific dietary tags (e.g., Vegan, Vegetarian, Gluten-Free).
*   **Authentication & Security:** Implemented **JWT (JSON Web Tokens)** and **Bcrypt.js** for secure admin login and role-based access control.
*   **Media Management:** Handled secure server-side file and image uploads using **Multer**.

## 💻 Frontend (React.js)
*   **Client Interface:** Modern, responsive UI using React.js (v18), Tailwind CSS, and Framer Motion for smooth transitions.
*   **Admin CMS:** A fully functional dashboard for the client to independently manage:
    *   Menu items (Adding/updating products, prices, images, and dietary labels).
    *   Hero section text and contact information.
    *   Automated QR Code generation for physical tables.
